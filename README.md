# Değer Partisi Mersin İl Başkanlığı — V4

GitHub Pages için hazırlanmış tek sayfalı, mobil uyumlu V4 sürümü.

## V4 özellikleri
- Kullanıcının sağladığı Değer Partisi Mersin amblem görseli
- Mersin panoramalı açılış
- Mobil uyumlu animasyonlu modern tasarım
- İl Başkanı tanıtım alanı
- Yönetim Kurulu alanı
- Haberler ve Duyurular
- Etkinlik Takvimi
- Fotoğraf Galerisi
- QR / iletişim görseli
- Telegram, Instagram, X, TikTok, web ve e-posta bağlantıları
- Mersin haritası
- Başvuru / iletişim formu (e-posta uygulamasını açar)
- PWA manifest + service worker

## GitHub'a yükleme
V4 klasöründeki index.html, manifest.json ve sw.js dosyalarını repository köküne; assets klasöründeki dosyaları da assets klasörüne yükleyin.

Not: İl Başkanı adı/fotoğrafı, yönetim kurulu isimleri ve il başkanlığının kesin açık adresi verilmediği için bu alanlar güvenli biçimde hazır şablon olarak bırakılmıştır.
